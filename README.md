# SUTI–Bridge–LivingMath

Исследовательская система: исходный текст → формализация → условные модели →
свидетели и контрпримеры → сохраняемая история исследования. MCP-интерфейс
объединяет LivingMath, проверку исходных схем SUTI и алхимическую модель ALCH006.

Текущий продукт: **`v0.1.0-developer-preview`**: автономный assurance CLI и 55 MCP-инструментов (44 прежних +11 новых). [Установка и полный ручной путь](README_QUICKSTART_RU.md), [CLI](CLI_REFERENCE.md), [границы возможностей](LIMITATIONS.md).

Единое assurance-ядро сохраняет точные байты ASSURANCE-003; базовый production слой observer012 сохранён. В каталоге legacy также остаётся experimental meaning014, который эта поставка автоматически не активирует. R3 с двумя внешними техническими участниками пока PENDING: установленный preview не означает финальную готовность или научную состоятельность интерпретаций.

## Установка и первый запуск

Нужны Linux x86_64 с Landlock, Python 3.12/3.13, Git и доступ к сети для
зависимостей и первоначальной загрузки публичного словаря токенизатора.

```bash
git clone https://github.com/R-Commons/LivingMath.git
cd LivingMath/live_math_mcp_prod
python3.13 -m venv .venv
. .venv/bin/activate
python -m pip install --require-hashes -r requirements-019.lock
python -m unified_system.local prepare --instance development
python -m unified_system.local serve --instance development
```

В другом терминале, из того же каталога и окружения:

```bash
python -m unified_system.local smoke --instance development
```

Это настоящий HTTPS/OAuth MCP-клиент. Он проверяет обнаружение 44 инструментов
и выполняет read-only вызовы без запуска LLM. Приватные данные экземпляра
создаются в `~/.local/state/livingmath/checkouts/development/`.

Подробно: [установка, запуск и подключение ChatGPT](docs/INSTALL.md),
[использование и точные JSON-запросы](docs/USAGE.md), [тестирование](docs/TESTING.md).
GitHub Actions пока завершается до запуска jobs: [данные и RCA](docs/CI_STATUS.md).
Для LLM-формализации требуется отдельно включить существующий Codex backend;
инструкции описывают вход через ChatGPT без API-ключа.

Источниковые адреса сохраняются. [Точный состав публикации](docs/PUBLICATION.md).

## Что предлагаем автору SUTI

В [отдельной папке предложений](suti_author_proposals/README.md) собраны изменения
и уточнения, которые **мы предлагаем добавить или обсудить в SUTI**:

1. Уточнить лимит меню: считать действия отдельно от `pause/skip/exit`.
2. Согласовать обмен рабочими файлами и обратным разбором.
3. Сохранять разные оси статусов и уточнить возможные зависимости.
4. Установить область применимости межфайловых условий и свидетелей.
5. Согласовать проверяемое сопряжение native SOMA/SUTI с прогнозом аудитории проектов.

Каждая карточка содержит основание, варианты решения и проверку. Это наши
предложения, а не принятые автором изменения или официальная реализация SUTI.
Ответ автора по этим карточкам пока не зафиксирован. Исходный runtime SUTI
здесь не исполняется; проверяются опубликованные схемы и условные модели.

## Известный результат Meaning014

На 24 новых открытых фрагментах C сформировал 8 различающих вопросов;
равно информированный B+ получил те же 8. Научный итог —
**`FAIL_NO_GAIN_OVER_B_PLUS`**. Рекомендован основной путь B/B+;
C остаётся экспериментальным. Независимой человеческой разметки нет,
семантическая accuracy и noninferiority не установлены. Три контрольных
случая закончились `COST_BOUND`; отсутствующие ответы не подменены.

Конечное доказательство относится к заявленной модели и предпосылкам.
`COMPLETED` означает завершение workflow; оно не присваивает `verified`,
не удостоверяет смысл исходника и не даёт разрешения на физическое исполнение.
Подробнее: [исследовательский статус](docs/RESEARCH_STATUS.md),
[полный отчёт](meaning_pivot014/USER_MODEL_REPORT.md), [RCA](meaning_pivot014/RCA.md).

Правила участия: [CONTRIBUTING.md](CONTRIBUTING.md).

## Коммерческий пилот Roblox

[ROBLOX-PRED-001](roblox-pred-001/README_RU.md) содержит самостоятельный Python-пакет,
семь таблиц Parquet/DuckDB, защиту от future leakage, временные splits и M0/M1.
Расширенная выборка содержит946 игр из чартов, публичных портфолио и жанрового
поиска. Для классификатора подготовлен501 пример:249 с высокой аудиторией и252
с низкой; train/validation/test300/100/101 разделены по создателям и близким
описаниям. Слабые метки активности не объявлены финансовыми исходами.
TF-IDF baseline: balanced accuracy61,4% на101 тестовой игре. Для SUTI–LivingMath
подготовлен тот же слепой тест; его результат ещё не измерен.
[Данные, подтипы отрицательных примеров и команды](roblox-pred-001/docs/CLASSIFIER_PILOT_RU.md).
Ежедневный сбор отключён; накопление90-дневной истории для быстрого теста не требуется.
