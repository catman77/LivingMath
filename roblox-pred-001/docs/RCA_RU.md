## R1 — Нет разрешённой временной выборки

Пользователь подтвердил отсутствие собственных проектов и исторической/лицензированной
выгрузки. В актуальном Games API проверен текущий snapshot шести намеренно выбранных
игр и каталог одного creator, а не population frame. Нет версий до исторического t0,
30 ежедневных future observations, наблюдения всех неуспешных проектов и точной
даты релиза. Creation2013–2019 не датирует нынешнее описание. Нули текущего playing
не являются отрицательными исходами исследуемого горизонта.

Минимальное действие: разрешённая выгрузка с timestamps/provenance и полной рамкой
включения, либо правомерный Pfirst с последующим дозреванием горизонта.

## R2 — Публичный HTTP200 не снимает ограничения ML-использования

[Roblox User Terms](https://en.help.roblox.com/hc/en-us/articles/115004647846-Roblox-Terms-of-Use),
разделы9.2.4–9.2.5 effective2026-11-01, ограничивают автоматическое ML/AI получение
данных. [Rolimon’s terms](https://www.rolimons.com/termsandprivacy) ограничивают
автоматизированный и коммерческий сбор. Поэтому новые массовые запросы и scheduler
не запускались. Это gate конкретного протокола, не универсальное правовое заключение.

Минимальное действие: документированное достаточное основание с точной областью
ML/коммерческого использования. Код проверяет наличие и неизменность документа,
но не превращает его в автоматически удостоверенное право. Собственный API key
не объявлен решением этого вопроса.

## R3 — Native runtime и задачное отображение различны

В соседнем SOMA действительно имеется пятиканальный числовой адаптер. Недостаёт
согласованного причинного mapping из Roblox-концептов/снимков, probe schema и readout.
В подключённом LivingMath доступны source transformations и lifecycle; готовый
native Roblox predictor не идентифицирован. Отсутствует новый native прогон,
поэтому нельзя заключить ни о пользе, ни о несостоятельности теории.

Минимальное действие после R1/R2: зафиксировать mapping существующих операций,
источниковые адреса и frozen schema, затем сравнить с обычным ML и переставленными
контролями. [Карточка005](../../suti_author_proposals/005-native-prediction-binding/README.md)
содержит варианты, а не новый утверждённый механизм.

## R4 — Ограничения минимальной реализации

В версии A неизвестные клоны автоматически не распознаются; проверяются известные
группы. Неполная cohort блокирует evaluation вместо неявного complete-case отбора.
Сборщик ограничен одним циклом до50 IDs; новые batches/масштабирование требуют
отдельной проверки. Консервативный daily-slot target отличается от дневного mean CCU.
Порог top-decile при ties может давать другую долю positives. Калибровка,
статистическая мощность, bootstrap CI, genre-holdouts, M2/H1 и экономика ещё не
исполнялись. Нельзя объявлять их PASS по факту успешного synthetic smoke.
