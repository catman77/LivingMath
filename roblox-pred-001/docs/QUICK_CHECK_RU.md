# Быстрый срез для модели

> Этот первый набор50 топ-игр сохранён. Актуальная [расширенная выборка](CLASSIFIER_PILOT_RU.md)
> включает946 игр и501 обучающий/тестовый пример с обоими классами.

По уточнению пользователя используем один срез топ-проектов и разумные прокси.
Ежедневный timer отключён. Ждать 90-дневного горизонта для этой проверки не нужно.

Получено **50 игр из официального Top Playing Now**, у всех50 есть описание,
дата и показатели аудитории. Это новая выборка топ-игр, а не прежние15 ID создателей.

- `description` — полное описание из API.
- `launch_date_proxy` — дата создания universe, прокси даты запуска.
- `current_players` — текущий онлайн, основной показатель аудитории.
- `visits_total` — накопленные посещения.
- `visits_per_day_since_creation_proxy` — visits / max(возраст в днях,1),
  грубый прокси масштаба активности; не измеренный рост или DAU.

Данные находятся в `data/quick-top/20261101T173137064299Z/`:
`top_games.csv`, `top_games.json`, `model_input.jsonl`, `audience_labels.csv`
и короткий `MODEL_PROMPT_RU.md`. Вход модели содержит описание, жанр и дату;
аудитория/ранг вынесены отдельно, чтобы сравнить ответы после их фиксации.
Выручка не требуется и в этой таблице отсутствует.

```bash
python scripts/quick_top.py --limit 50
```

Команда делает два публичных запроса: chart и карточки выбранных игр.
[Официальное описание API Charts](https://devforum.roblox.com/t/official-list-of-deprecated-web-endpoints/62889/59).
Машинный результат — [quick-top.json](../reports/quick-top.json).
Это быстрый сравнительный тест на уже популярных играх; прогноз будущего релиза
и преимущество SOMA/SUTI пока не измерялись. Модель этим сборщиком не запускалась.
