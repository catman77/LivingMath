# Фактический запуск формального сравнения

Гипотеза пользователя: формальный базис даёт более тонкие признаки смысла.
Прогон запущен 2026-11-02. Сначала сравниваем
одинаковые тексты; скриншоты — отдельное испытание, которого здесь пока нет.

## Зафиксированная конструкция

Используются существующие `observer012/1`, `source-relations012/1`,
`source-observer012/1`, `typed008/1`, реальный proposer/critic и независимые
компилятор/проверка LivingMath. Новых фундаментальных операций или DSL нет.
Первый реальный MCP case #4553 в `BRIDGE_QA_ROBLOX_FORMAL_PILOT_001` завершён
`SOURCE_META_FORMALIZATION`; source snapshot #4551 сохранён на сервере.
Это META_ONLY, не свидетельство исполнения игровых механизмов.

Основа признаков: типизированные состояния, их source coordinates/features,
отношения и пути длины 2, наблюдатели, неопределённость и фактически выполненные
проверки. Общая численная проекция — 512 signed hash coordinates, L2-нормализация.
Не создаются вручную категории вида «хороший геймплей» или «успешная монетизация».
ID, хеши, адреса, split и labels не являются признаками. Source addresses остаются
в доказательных артефактах. Открытые лексические поля схемы не объявлены
универсальными семантическими атомами. Это конкретная проверяемая проекция
существующих формальных объектов, не доказательство полноты смыслового базиса.

## Варианты сравнения

- A: сохранённый TF-IDF+metadata baseline.
- B+: те же признаки A + LLM source graph с тем же proposer/critic, до формальной компиляции.
- C: те же признаки A + существующие формальные модели/свидетели LivingMath.
- C-shuffled: те же реальные формальные признаки, переставленные внутри каждой
  части по фиксированному seed, без новых model calls.

Одинаковый logistic readout, C=1, class_weight=balanced. Train 300,
validation 100, test 101 из прежней зафиксированной выборки 501 игры. Параметры не настраиваются по
новым test scores. Дополнительно измеряется formal-only readout. Метрики прежние,
основная — balanced accuracy; paired bootstrap по test split components.

## Исполнение и границы

Весь набор 501 игры обрабатывается установленным продуктовым кодом в отдельных
приватных DAV-журналах. Исходный MCP-пробник #4553 — через действующий endpoint;
пакетный прогон — теми же установленными библиотеками, без загрузки 501 задачи
в рабочую SQLite. Четыре source workers используют существующий подписочный
Codex backend, без API key. Это model inference существующего приложения,
не агенты с инструментами. В source model передаются только текст/название,
без меток, аудитории, рейтинга, даты и split. Даты/жанр доступны одинаковой
metadata-ветке всех классификаторов.

Каждый case: source_views=1, workers=16, models=4, retries=1. Номинально два model
calls; верхняя граница повторов сохраняется. Math workers сохраняют прежние
CPU/wall/IO bounds. Каждый source/model/check сохраняется с SHA и case history.
Отсутствие графа не превращается в нулевую семантику: coverage/missingness
сохраняются; для failed test sources применяется заранее объявленный A-fallback.
Три последовательных случая недоступности backend останавливают очередь.

Прогон возобновляемый; завершение/ошибка записываются в status.json и report.md.
На компьютере отправляется отдельное desktop-уведомление. Приписывать фоновое
сообщение в чат этому механизму нельзя. Итоговый статус COMPLETED не присваивает
verified, не подтверждает истинность источника и не даёт execution grant.
Native SUTI runtime отдельно не заявляется исполненным: измеряется реализованный
формальный путь SUTI–Bridge–LivingMath и его классификационный readout.

## Сохранённый отрицательный результат при запуске

В предварительном запуске `20261102T000317Z` первый case получил
`CRITIC_REFERENCES_FOREIGN_RELATION`: компилятор отклонил несогласованные ID
отношений в ответе critic. Ограничение сохранено, формальных признаков у этого
case нет. Исправлен только адаптер B+: он читает исходный типизированный ответ
LLM даже при отказе формального согласования. Это позволяет честно проверить
вклад компиляции относительно семантического разбора.

После исправления адаптера создан новый freeze `20261102T000934Z`, до обучения
классификаторов. Исходная история и вызовы первого case перенесены SQLite Backup
API, без повторной генерации или удаления отказа. Все остальные cases проходят
продуктовый pipeline заново. Код, входы и исходный baseline защищены хешами.
