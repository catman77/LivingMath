# Публичное наблюдение через Roblox API

Дата: 2026-11-01. Основание изменения — прямое указание пользователя продолжить
обычную работу с официальным публичным API. Предыдущий общий запрет коллектора
был чрезмерным: он смешивал доступ к публичной статистике с отдельным вопросом
использования контента при обучении моделей. Предыдущие результаты сохраняются.

Режим PUBLIC_API_OBSERVATION разрешает ограниченные GET к документированным
публичным методам Games API без cookie, ключей и обхода авторизации. Это сбор
описаний проектов и доступных агрегатов для исследования рынка; статус не является
декларацией новой лицензии на весь контент и не удостоверяет доходы.

Источники:
- https://create.roblox.com/docs/cloud/reference/domains/games — карточки игр,
  каталоги создателей, votes и counts, включая методы без cookie.
- https://create.roblox.com/docs/production/analytics/monetization — revenue в
  Analytics владельца/группы с соответствующими правами.
- https://create.roblox.com/docs/cloud/guides/analytics — universe.analytics:read
  и доступ к конкретному universe; это другой API, не публичная карточка.

Код сохраняет raw responses, SHA и время. Отсутствующие значения остаются NULL;
price, visits и CCU не переименовываются в выручку. HTTP429/401/403 останавливает
сбор без повторов и смены идентичности. Максимум12 запросов за запуск, максимум
2MB на ответ, пауза не менее1 секунды, конечный timeout. Закрытые endpoints не
запрашиваются. Публикации реальной выручки можно позднее добавлять как отдельные
источники с датой, периодом и валютой; оценка дохода по трафику будет только estimate.

История публичных snapshots начинает накапливаться с фактического первого capture.
Текущие тексты не подменяют исторические версии. Дата создания universe не
объявляется первой датой публикации. Наличие API не создаёт отсутствующую историю
и не делает выручку чужого проекта публичной.
