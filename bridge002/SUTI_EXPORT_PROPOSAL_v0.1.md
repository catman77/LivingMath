# Рабочий файловый интерфейс SUTI → Bridge

Текущий цикл работает непосредственно с файлами предоставленных автором архивов.
Официальный API/экспортёр и релиз не требуются. archive SHA, member path, raw SHA
и source spans фиксируют конкретный текущий снимок; изменение файлов создаёт новый
снимок и новую проверку, а не запрос на сертификацию релиза.

working_source.py читает точные bytes без исполнения кода архива. source_contract()
извлекает явно объявленный фрагмент с проверяемыми адресами. choice_case.py содержит
две конкретные модели этого фрагмента; неизвестный смысл не объявляется сохранённым.
working_mcp_qa.py создаёт настоящие source/counterexample записи только в отдельной
QA-копии, затем вызывает реальные MCP context/normalize/audit. Native adapter не
выдумывается; модель не получает grant/verified.

Предыдущая формальная export-proposal сохранена в истории и не является gate
этой разработки. Подпись источника не подменяется fixture-ключом: основанием служит
фактическое пользовательское разрешение, зафиксированное как такое, без выдуманной
криптографической аттестации автора.
