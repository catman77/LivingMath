# RCA — MEANING-PIVOT-014

## Решение

**Научный критерий014 не выполнен: FAIL_NO_GAIN_OVER_B_PLUS.** На24 новых открытых
авторских фрагментах C сформировал8 различающих вопросов; равно информированный B+
получил те же8. Дополнительных источниковых отношений, доступных только C, нет.
Содержательная accuracy не измерена: независимых human labels нет.

Применён STOP/PIVOT из ТЗ: B/B+ — основной рекомендуемый workflow, C оставлен
experimental. Новая ступень observer015 не предлагается. Это не доказательство
невозможности всех будущих source-discrimination методов; это отрицательный итог
именно реализованного ограниченного механизма и данного открытого пилота.

## Где расположен причинный разрыв

В неизменённом013 `observe013.align()` привязывает предложенные значения и цитаты;
`realization012.compile_semantics()` компилирует принятые гипотезы;
`inference013._plan()` принимает KNOWN как ограничения; `_question()` и
`reference013.enumerate_reference()` перебирают один объявленный finite plan.
`_reports()` создаёт условный конфликт лишь после дополнительного общего смысла
EQUALITY/RETURN. Это правильные условные вычисления, не независимый S→H oracle.

014 не пытается исправить эту границу ещё одной математической аксиомой.
`meaning014.family()` сравнивает содержательно отличные H, сохраняет вопросы,
предположения, цитаты и необходимость дополнительного свидетельства. Прогнозы H
не превращаются в источник истины. Их Gate6 encoding явно помечен как encoding
уже объявленных forecasts, а не новое открытие.

В пилоте это ограничение проявилось буквально: все вопросы C уже находились
в общем A0/его прогнозах и воспроизводились отдельным stdlib checker B+.
Дополнительного источникового наблюдения, которого B+ не получил, не появилось.
Дальнейшие finite receipts не могли изменить информационное содержание входа.

## Реальный ограниченный source witness

На настоящих байтах Блока функция `source_list_witnesses()` независимо от labels
LLM строит буквальные проекции comma-separated перечислений. Выявлены четыре
общих элемента, другой порядок и добавленная деталь. Их адреса проверяются по
оригинальным UTF-8 ranges. Вектор shared=true / sequence=false даёт конкретный
контрпример к импликации shared-equality→sequence-equality в этой **буквальной**
области. При отзыве наблюдения одного списка равенство полных списков становится
допустимым completion, не новой источниковой записью.

Это реальное источниковое различение узкой проекции, а не вручную подставленные
константы из присланного fibre_probe. Оно не определяет физическое тождество,
смысл «всё», референцию персонажа или исполненный мировой цикл. B+ на тех же
байтах воспроизводит его. Поэтому свидетель не засчитывается как преимущество C.

## Сад: определённый вопрос, но нет источникового победителя

Первый миницикл использовал действительный исходник4415. Реальные два source-only
LLM-вызова сохранили полную A0, разные критерии тождества и адресованные цитаты.
Критерий индивидуальности сада текст не фиксирует; нет основания объявить одну
модель мира верной. Обязательство сформулировано конкретно: какое свойство входит
в критерий сохранения сада и как оно соотносится с деревом/местом/историей.

Первый минискрипт также выдал общий P→Q пример, не связанный с выбранным вопросом.
Он сохранён и явно исключён из заявленного выигрыша (`mini/assessment.json`).
Содержательная часть миницикла — реконструкция/источниковый review, не свежая
независимая проверка. В финальном коде forecast vectors и literal witnesses
разделены и имеют разные scopes.

## Обнаруженные исправленные ошибки реализации

- A0 сохраняется append-only до critic/repair. Ошибка typed mapping не стирает
  читаемый ответ. Исправление H не наследует approval изменённых source fields.
- H commit и discriminator — отдельные Journal records; исходная A0, старые H,
  review и single repair сохраняются. Выбранные evaluator Q/M/proof/gold в critic
  не передаются. При этом critic видит общий A0 и его **невыбранные source forecasts**;
  он не является слепым или независимым источниковым экспертом.
- Conflict из source review не объявляется источниковым/мировым refutation.
- Нет target Network — не значит отсутствия полезной модели: A0 и отрицательные
  META_ONLY reports доступны первыми, finite details вынесены в export.
- Три upstream timeouts первоначально выглядели как UNSUPPORTED_ARTIFACT.
  Исправлено: COST_BOUND с причиной MODEL_CALL_WALL_BOUND. Отсутствующая A0 не
  синтезируется. В раннем runner `None == None` ошибочно давало A0_preserved=true;
  начальные summaries сохранены, итоговая availability рассчитана корректно.

## Неустранённый лимит — не скрытый PASS

K4415, KREORDER, KNO_REPEAT не вернули финальную A0 за120s. В CLI events нет
завершённого agent message, answer.json отсутствует. Это реальные COST_BOUND,
а соответствующая новая014 семантическая проверка — NOT_TESTED. Дополнительных
попыток до случайного успеха не было. Старые013/012 результаты не переписаны.

Где именно потрачено время внутри hosted backend, не наблюдается: локальное
ожидание pipe измерено отдельно, hosted queue/reasoning разделить нельзя.
Гипотеза: обязательная большая совмещённая схема A0+нескольких typed H увеличивает
цену. Это не доказанная причина таймаута. Минимальное продуктовое направление
после STOP — обычный читаемый A/B без обязательного C-family payload в первом
ответе, а не новый solver или повышение wall budget до многочасового перебора.
Текущий014 пакет остаётся приватным экспериментом, не релизом готового универсального
семантического формализатора.

## Границы исследования

24 новых фрагмента — авторские AI-generated originals четырёх стилей. Они открыты
разработчику; historical-style тексты не являются архивными первоисточниками.
12 мутаций учтены отдельно; точное преобразование входа проверено программно,
содержательная правильность LLM-ответов не подменена сравнением хешей.

Корпус, rights, questions rubric и source prompt/schema зафиксированы перед
cohort inference. Исполняемый checker дорабатывался в разработческом прогоне;
итоговая приёмка использует **sealed final code + recorded source-only replay**.
Это инженерный диагностический результат, не prospective blind study.

Двух human reviewers нет. Accuracy/coverage относительно gold, unsupported-claim
rate, noninferiority, CI и cost per independently supported gain оставлены null
или NOT_TESTED. D — pinned013 engineering replay общих реальных014 source accounts,
а не новая013 LLM generation и не равный литературный конкурент.

Production/RH/FTL/SUTI не изменялись. Проверки SQLite/цепочек выполнены на приватных
копиях ранее закрытых BackupAPI snapshots. Live вызовы были только read-only
status/health: production остался012 с тем же audit head.

## Исправленная ошибка recorded replay

При первом recheck некоторые repair requests не находили записанный ответ:
JSON в Journal канонизирует порядок ключей, а исходный prompt был записан в порядке
Pydantic fields. Содержимое JSON полностью совпадало; строковые bytes prompt — нет.
Replayer теперь сопоставляет SHA canonical JSON **со всеми исходными полями**,
не игнорируя тексты, списки, source hashes, candidates или feedback. Новых model
ответов не запрашивал. Неуспешные replays сохранены отдельно; финальный replay
использует настоящие записанные repairs. Это исправление harness, не «успех» источникового
смысла. Фактический source backend имел4 wall timeouts, не эти harness errors.
