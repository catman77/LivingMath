# Symbolic V1 Implementation Plan

**Goal:** add full symbolic histories and a reproducible train-only grammar experiment to the existing MCP, then deploy without changing its public address or historical data.

**Architecture:** `symbolic/` is an additive pure-Python layer. Immutable symbolic objects use the existing Workspace/journal/blob store. New isolated subprocess jobs reuse the installed White Star isolation and the actual supplied ReversibleUDAV clock; the numerical White Star package stays byte-identical. Three new MCP tools expose explore, inspect/export and replay. The existing project registration remains mandatory.

**Tech Stack:** Python 3.13, stdlib, existing strict JSON Schema validator and MCP SDK 1.30.

**Spec:** `docs/LIVINGMATH_SYMBOLIC_V1/{01_TZ_SYMBOLIC_V1_RU,03_API_AND_SEMANTICS_RU,04_ACCEPTANCE_TESTS_RU}.md`.

## Global Constraints

- P0 and P1 both required; finite local search, never exhaustive word/grammar enumeration.
- Full original UTF-8/hash/spans, nonsemantic tokens, declared boundaries and append-only provenance.
- Separate literal, local/global alpha, SP normal-form equality and finite observer indistinguishability.
- No LLM in kernel, search, induction or blind scoring. No mathematical `verified` or external execution grants.
- Existing 72 MCP input/output schemas, White Star application and 75 supplied files unchanged.
- Same production origin/OAuth/network configuration and existing databases; online and quiescent backups before cutover.

- [x] Implement frozen State/Span records, exact word hashes and content-addressed acyclic operation nodes; source decoding supports codepoint, whitespace, line and explicitly spanned literal tokens. Preserve gaps and NFC source maps.
- [x] Implement CONCAT/SPLIT, bijective RENAME vs arbitrary SUBSTITUTE, REVERSE, SP_INV, deterministic leftmost REDUCE_SP and INSERT_CANCEL_PAIR. `apply()` returns new states plus replayable operation arguments and cancellation logs.
- [x] Observe literal/boundaries, local/global alpha, oriented adjacency, bounded contexts, composition, declared hierarchy and SP profile without mutating input. Compare only explicitly selected observer projections.
- [x] Generate a fixed number of local candidates per step using the actual ReversibleUDAV clock; compare sets of new witness hashes by inclusion, log Pareto frontier and seeded tie choice. Bound nodes, total tokens, observations and output.
- [x] Run supplied fixture checker first, then >=30 seeds of generated words including epsilon and multibyte sources. Verify invalid spans, incomplete histories and domain restrictions fail explicitly.

## Task 2: train-only finite grammar induction and blind harness

- [x] Derive finite positional/context/count predicates from train alone. Fit a bounded deterministic rule tree and retain support/counterexamples; predictions accept arbitrary opaque tokens. - [x] Keep generators, labels and sealed test outside the learner module. Predeclare 20 seeds and balanced G1/G2/G3 train/validation/test sets; freeze all models before reveal. G4 is a separate non-identification control.
- [x] Compare unigram, bigram, simple_context and lossy 2D controls on identical data/budgets; report per-seed balanced accuracy, NLL, rule witnesses and dispersion, including losses. Run A–G ablations and record which preservation quotient each tests.
