# После PATCH005: отдельная исследовательская программа

Этот план не является частью реализованного патча и не утверждает достижимость
его дальнейших гипотез. Результаты PATCH005 измеряют конечную корректность поиска.

## 1. Различение recursive base cases

Зафиксировать независимые split по паритету/длинам0,1,2. Разделить native semantics
пустого фрагмента от действующего непустого dataset ingress. Сравнить retained
rivals на размеченных извне membership queries; не выбирать по holdout accuracy.
Проверить устойчивость при биективном переименовании и альтернативных источниках.
Критерий: исчезновение ложного no-compatible без роста общего перебора.

## 2. Ориентированные prefix relations / Dyck

Сначала определить source-grounded направленное отношение, различающее SP/PS,
которые equality-only catalog отождествляет. Сконструировать typed prefix
composition и независимый oracle/проверку убывания и zero-redex interleavings.
Не вводить числовой pair_0_max под другим именем, builtin parser или языковой флаг.
Ограничить конечные домены до эксперимента, сохранить отрицательные результаты.

## 3. Межстрочный корпусный перенос

Переходить после независимой проверки stage2. Восстановить R(a,b|C) с настоящими
line/quatrain/century boundaries, заморозить источник/edition/normalization,
I–VIII train / IX–X heldout и private labels. Сравнить shuffles, punctuation,
line-length controls, literal/global-alpha regimes при одинаковых наблюдениях.
Большое число witnesses не объявлять смыслом; при отсутствии преимущества
зафиксировать отрицательный результат и остановить следующую стадию.
