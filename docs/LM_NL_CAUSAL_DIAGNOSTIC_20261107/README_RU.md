# LivingMath / NLProposalBridge — причинный аудит, 7 ноября 2026

**Назначение:** независимая диагностическая проверка, не новый релиз сервера. Исходный production MCP v0.4.10 не изменён. В пакете есть готовое ТЗ и промпт для кодового агента на LM-NL-CAUSAL-003.

## Вывод

На пяти precommitted потенциально неоднозначных фразах U21–U25 обычный **однократный swap двух кванторов** над базовой формулой воспроизводит **все пять** ранее выданных White Star широких AST с **точно совпадающими SHA256**. Каждый узкий/широкий вектор различается в **176 из 530** конечных моделей. При воспроизведении использованы **0 вызовов LLM и 0 вызовов Белой звезды**. Это сильный *отрицательный результат для предположения о необходимости именно White Star для этих 5 новых AST*, но не отрицание потенциальной пользы всей её архитектуры.

Проверка выполнена по опубликованным ранее precommitted AST; SHA этих базовых AST совпали с фактически сохранёнными source-only кандидатами. Это **не полноценный production replay исходного provider receipt**: тот сейчас недоступен из текущего MCP-подключения. Не путать эти два уровня доказательности.

## Содержимое

- `REPORT_RU.md` — RCA, выводы, статус доступа к MCP, ограничения.
- `TZ_CODE_AGENT_RU.md` — точный контракт opt-in `formal_nl_redecode`, однофакторный sham, finite-model классификатор, тесты, критерии.
- `PROMPT_CODE_AGENT_RU.md` — задача кодовому агенту.
- `C_RECOVERY_RU.md` — восстановление ранее завершённого, но непрочитанного C-запуска **без нового LLM**.
- `scripts/frozen_ast_counterfactual.py` — независимое эталонное исполнение (stdlib Python).
- `scripts/test_counterfactual.py` — автоматические локальные тесты.
- `fixtures/` — копии опубликованных precommitted references, сопроводительного score и run manifest. U26 оставлен с маркировкой ошибочного эталона, не подменён.
- `results/` — результат самостоятельной локальной проверки.
- `SOURCE_SHA256SUMS.txt` — SHA256 данных и скриптов.

## Воспроизведение

Из распакованной директории:

```bash
python3 scripts/frozen_ast_counterfactual.py
python3 scripts/test_counterfactual.py
```

Не требуются интернет, сервер MCP, API key, numpy и другие пакеты. Исходные тексты русские, но код проверяет только AST и явные интерпретации отношения. Он **не доказывает допустимость трактовки по естественному языку**.
