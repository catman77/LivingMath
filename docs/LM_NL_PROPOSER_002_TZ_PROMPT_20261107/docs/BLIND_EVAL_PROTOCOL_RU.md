# Независимый слепой контроль: схема, не готовые метки

ПРИЛАГАЕМЫЕ `fixtures/DEV_SOURCE_AND_FOL.json` — **только открытые dev**. Агент вправе их прочитать для разработки. Они не могут служить blind performance benchmark. В том же ZIP **нет скрытых целевых формализаций**, чтобы кодовой агент не мог нечаянно или сознательно выучить их.

Организовать независимый держатель holdout-меток/намерений (сам заказчик, эксперт или изолированный eval runner, недоступный production model и разработчику). Подготовить ≥36 новых исходников, минимум6 разных структурных феноменов. Каждый source имеет случайный внешний id, SHA и права. Не класть метки/формулы/ключи в prompt, source metadata, docs, tool logs доступные генератору. Запустить source-only G0 и WhiteStar G1 при одинаковых бюджетах; кандидаты freeze/sha; затем проверить человеком допустимость альтернативных прочтений и контрастные контрмодели.

Обязательно хранить `NOT_EXECUTED` если external adjudication не проведена; нельзя считать synthetic oracle human agreement. Метрики сохраняют abstain, unknown, not_supported, false_equivalence. Случаи, которые нельзя выразить в выбранной сигнатуре, остаются `NO_WELL_TYPED_DECODING` и оцениваются отдельно.
