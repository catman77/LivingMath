# RCA и решение о том, что исправлять **сейчас**

| Наблюдение | Установленная причина | Статус | Решение |
|---|---|---|---|
| `symbolic_v1` застревает в ε при наличии иных узлов | Продолжение только по одному ребёнку; альтернативы сохраняются, но не состоят в честной рабочей очереди | Воспроизведено на live MCP | **P0 FIX** в opt-in стратегию |
| `SPLIT` тратит большую часть попыток на дубли | Учёт только `(node,op)`; position выбирается clock с повтором | Воспроизведено | **P0 FIX** per-param work items |
| Pareto = random при множестве буквальных наблюдателей | `witness_set` = SHA для целого наблюдателя, почти каждый новый объект уникален | 96/96 шагов в трёх парах опытов | **P1 FIX** новой политики описания новизны, legacy не менять |
| Перестановка одинаковых операторов меняет поиск | Используется `operators[clock % n]`, clock расходуется также на arguments | Воспроизведено | **P0 FIX** детерминированный независимый от порядка work scheduling |
| Разные CAT-адреса дают одну sigma | Сигнатура усечённая и не хранит идентичность понятия; полные записи остаются в атласе | 112→48 сигнатур при w=(1,1) | **P2 OPT-IN** distinction-aware tie-break, не изменять quotient глобально |
| `source_relations` не влияет на C++ selector | Не входит в numeric native контракт; статус семантики не удостоверен | Доказано контрольной интервенцией | **НЕ БАГ**, не внедрять невалидированные смыслы |
| Численный расписатель не зависит от выбранной CAT-карты | Алгоритм `first=(clock + 7*t + seed) % N` | Подтверждено исходниками и вмешательством | **ОТЛОЖИТЬ** изменение generator feedback: пока нет положительной причинной приёмки |
| Теневой MAIN/SHADOW банк теряет гипотезы | Ошибка **в лабораторном** `learner007.py`, не в native Удаве | Post hoc регрессия | **НЕ ПЕРЕНОСИТЬ** в сервер; лабораторный алгоритм не должен стать MCP-функцией |
| Вопросно-зависимый search vs sham иногда хуже | Зависит от задачи/грамматики, механизмы не стабильно лучше | Многократные отрицательные контроли | **НЕ ВНЕДРЯТЬ** как дефолт |
| Пользователь хочет LLM для смыслов | Смысловую функцию должен выполнять LLM, а Удав — структурный поиск | Архитектурное требование | **СТРОГИЙ ЗАПРЕТ** на internal theory generation |

## Важные инженерные границы

- `cat_distinction_tiebreak_v1` — не универсальное средство избежать коллизий и не доказанный способ найти научно важное. Это явный opt-in критерий для source-bound структурных различий.
- `history_identity=word` и `history_identity=provenance` — два осмысленных режима; нельзя подменять второй первым и считать одинаковые слова с различными историями одной траекторией.
- Не делать претензий на полный охват бесконечного/экспоненциального пространства. Платформа должна честно возвращать `BUDGET_EXHAUSTED`, `PARTIAL_PARAMETER_COVERAGE`, источник и сохранённый frontier.
- Не увеличивать квоты ради прогона: примеры исходного исследования специально малы.
