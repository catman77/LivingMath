# RCA: конечная полнота наблюдений и границы интеграции

## Причина исходного разрыва

Достижимость геометрического состояния в атласе не заставляет heuristic selector
его обслужить. Периодическое окно кандидатов и CAT score могут не предъявить
нужную точную работу. Preview кадров дополнительно не гарантирует полной
доставки даже вычисленных данных. Сам по себе ещё один seed это не исправляет.

## Исправление

Определён фиксированный scope `cj_v1` и наблюдатель знака произведения/абсолютного
доминирования. Исходный compiler строит атлас; adjugate construction даёт witness
каждой качественной цели. Независимый проверяющий восстанавливает атлас и весь
образ наблюдателя по рациональным ячейкам, не доверяя denominator planner.

Отдельный completeness-only worker выполняет обязательные работы через исходный
`cad.project`. Проверенные квитанции и checkpoint фиксируются одним commit
существующего Workspace; failed/uncommitted работа остаётся открытой. Полный
export не зависит от `decode_first_frames` или `frame_size`.

Новые witnesses имеют происхождение `CONSTRUCTED_CERTIFIED_WITNESS`.
Индекс орбиты проверяется исходным `WhiteStarOrbit`, но её предыдущий префикс
не исполняется. CAT/clock/graph исходного режима не используются и не меняются.

## Дефект общего экспорта, обнаруженный при интеграции

Generic `assurance_export` собирал object refs неизвестного ему `coverage.*`
журнала без source.add publication policy. Это могло выдать приватный source в
public/reviewers ZIP и создать bundle без поддерживаемого replay. Добавлен
явный отказ `COVERAGE_EXPORT_REQUIRES_PLAN_REF`; новый полный интерфейс —
`coverage_inspect`. Для проектов без coverage старое поведение сохраняется.

## Что не утверждается

- Конечное Q-покрытие не удостоверяет смысл, истинность или физическую модель.
- Floating phase/signature вспомогательны, не часть доказательства Q-покрытия.
- `base_v1` не дополняется выдуманными состояниями; новый режим его отклоняет.
- При остановке/квоте возвращается PARTIAL либо ERROR с открытым обязательством.
- `delivery_acked` — записанная декларация клиента с точным digest/count,
  не доказательство чтения/понимания внешней моделью.
- Production не устанавливался: его deployment-binding нельзя подменить
  успешно выполненным локальным HTTP/MCP прогоном.

Принципиального блокера конечной CJ-интеграции в проверенном scope не осталось.
Полнота бесконечного exact-raw режима и другие observers сюда не входят.
