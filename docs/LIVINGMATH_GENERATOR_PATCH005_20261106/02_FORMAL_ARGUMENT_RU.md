# Формальная постановка задачи mixed-length synthesis

Пусть Σ={S,P}, B_n=Σ^n, D_train⊂Σ*×{0,1}. Кандидат — типизированный AST `A` над разрешёнными примитивами `SPLIT`, `REVERSE`, `literal_word_equality`, `AND`, составленными в строго убывающую структурную рекурсию. Оценка функции частичная: `⟦A⟧_D(w)∈{true,false,UNKNOWN}`; вне ограниченного домена `D` нельзя отвечать false.

**PAL-рекурсия**:

- `P(ε)=true`, `P(a)=true`;
- `P(aub)=[a=b]∧P(u)`.

Доказательство эквивалентности конкретной интерпретации и палиндромности: индукция по |w|. Для |w|≤1 утверждение очевидно. Для |w|≥2, `w=aub` равно своему обращению `b reverse(u) a` тогда и только тогда, когда a=b и u=reverse(u). Индукционный переход реализуется двумя SPLIT, REVERSE+SPLIT, сравнением атомов, AND; рекурсия убывает на 2. Это **доказательство свойства заданной программы**, а не доказательство, что конечный train однозначно определяет программу.

**Конкретный AST**, уже найденный на Σ⁴:

```json
{"composition":"iterate_on_inner_fragment","trim_left":1,"trim_right":1,"fragment_operations":["SPLIT","SPLIT"],"relation":{"composition":"aligned_token_equality","base_max_tokens":1,"left_operations":["SPLIT"],"right_operations":["REVERSE","SPLIT"],"offset":0,"expected_equal":true}}
```

Обязательная семантика `base_max_tokens=1`: после полного снятия крайних атомов остаётся ε при чётной длине и один атом при нечётной. **Оба — true**. Иначе слово `SS` окажется ложно отрицательным и рекурсивное правило не перенесётся по паритету.

**COPY**: `C(w)` истинно при чётной длине и равенстве частей после `SPLIT` в середине. Его успешно находит текущий сервер на смешанных длинах — регрессионный эталон.

**Конечная идентифицируемость**: никакой конечный train не выделяет универсальную грамматику единственным образом. Если совместимы несколько AST, сохранять `UNDERDETERMINED`, rival models, AST digests, активные различающие запросы; до получения новых меток ни один rival нельзя называть теоремой.

**Структурная канонизация**: перестановка атомных имён — биекция Σ→Σ'; вычисление PAL/COPY сохраняет результат, включая Unicode-токены и реальные byte spans. Область применимости bound `max_tokens=8` остаётся явной; не расширять scope на произвольную длину из-за успешных 256/256.

**Критерий полноты на заданном конечном классе C**: если C явно содержит указанный рекурсивный AST и `⟦A⟧_D` согласуется со всеми train, вывод `no compatible typed composition` запрещён. Не требуется полнота по всем возможным грамматикам/программам.
