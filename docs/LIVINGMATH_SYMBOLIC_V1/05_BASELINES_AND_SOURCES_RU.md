# Исходные материалы, фактически проверенные ограничения и baseline

Этот файл **не содержит требований к изменению физических моделей** и не интерпретирует количество циклов β₁ как «количество смыслов».

## A. Источник математической постановки

В статье автора «Дрожь твари» (11 февраля 2025, PDF «Дрожь твари_ errorem — ЖЖ.PDF») предложено:

- Рассматривать несвёрнутую строку S/P как историю построения числа, а свёртку — отдельной операцией.
- Сохранять полные строки при арифметических операциях; одинаковое числовое значение не тождественно одинаковой структуре.
- Генерировать слова внешним субъектом с целью и обратной связью, не ограничивая историю только «кратчайшим путём к числу».
- В конце перейти к общей задаче исследования грамматики символов и вопросу **«что есть слово?»**.

Это цель тестов. Наши фиксированные S/P свойства — математические тесты, а не новое доказательство теории семантики.

## B. Фактический runtime к моменту ТЗ

Запрос к `mcp__LivingMath__bridge_system_status` и `white_star_status` от 2026-11-05:

- `v0.3.0-developer-preview`, рабочая White Star, 2 профиля `base_v1`/`cj_v1`.
- Старый schema `levinmas-white-star-request/1` ожидает `llm-white-star-concepts/1`, 3–64 concepts, 2 целочисленные координаты на concept, структурные evidence/axes.
- Лимиты включают `steps≤4096`, `candidates_per_step≤16`, `worker_cpu_s=5`, `worker_wall_s=6`, `worker_memory_bytes=536870912` и bounded output. Уточнить актуальные лимиты и ассоциированные hashes непосредственно в checkout/endpoint.
- `white_star_explore`, `white_star_inspect`, `white_star_replay`, `white_star_record_interpretation`, `white_star_validate_model` уже есть; новый API добавлять, не менять прежние.
- Численный kernel импортирован из неизменённого поставленного кода; `ready=true` не означает новой семантической способности.

## C. Исторические наблюдения из диалоговых опытов (считать наблюдениями, НЕ эталонными метриками для нового kernel)

Все прогоны ниже произведены со структурными **2D-кодировками**, а не полноценными символьными объектами.

| Опыт | Входная фича | Наблюдение |
|---|---|---|
| Малларме vs текст из X | позиция + длина строки | одинаковые численные показатели (657 сигнатур, 367 β₁, 416 карт) |
| Синтетика ABAB/BABA/ABBA/BAAB vs AABB/BBAA/ABAB/BABA | позиция + длина | совпадение 203 сигнатуры, β₁=53 |
| Те же строки | позиция + количество одинаковых соседних символов | A: 228/28, B: 221/35 (сигнатуры/β₁) |
| ABBA/BAAB переставлены | позиция + adjacency count | одинаковый результат 221/35 |
| ABBA/BAAB переставлены | позиция + зависящий от букв позиционный код | 140/116 против 148/108 |
| ABBA/BAAB переставлены | позиция + α-канонический рисунок повторений | одинаковые 166/90 |
| `ab=SSPPSPSP` vs `ba=SPSPSSPP` | позиция + префиксный S/P баланс | 431/81 против 433/79 |
| `cd=SPPSPSSP` vs `dc=PSSPSPPS` | те же фичи | 437/75 против 441/71 |
| S/P-инверсия ab/ba | те же фичи | raw β₁ меняется; не объявлять S↔P raw-графовым инвариантом |

Для старого ядра при полном нулевом 2D-кодировании была зафиксирована ошибка `not enough independent CAD charts`; **это не доказательство невозможности работы с нулевыми словами**, а ограничение этого старого интерфейса.

Некоторые перечисленные цифры появились в исторических MCP ответах; воспроизводимость в новой среде подтверждать **новыми фактическими прогонами**. Не копировать таблицу в итоговый отчёт как будто она повторно измерена.

## D. Что эти опыты на самом деле доказывают

- Тривиальное совпадение входных координат гарантирует совпадение детерминированных результатов при равном seed.
- Признаки энкодера способны сделать разные слова различимыми; это **не** означает, что ядро самостоятельно вывело грамматику.
- Raw β₁, количество сигнатур и карты — свойства численного исследования, сильно зависящие от входной параметризации; не метрики новизны смысла.
- Настоящий переход — сохранение самой истории и исследование отношений между **операциями и контекстами** с явными контролями и отложенными проверками.

## E. Обязательная граница истинности

1. **Доказано формально:** алгебраические факты о S/P-редукции, буквальные/α-равенства, корректность реализованных операций (после тестов).
2. **Проверено экспериментально:** воспроизводимые результаты конкретных вычислительных режимов, статистика скрытых грамматик (после запуска).
3. **Гипотеза:** перенос стабильных отношений с формальных слов на семантические структуры естественного языка.
4. **Не следует из результатов:** физическая материализация, FTL, предсказательная сила Нострадамуса, универсальная грамматика или происхождение субъективного смысла.
