# RCA и честные границы результата

## Исправленные дефекты при разработке

1. **Нестабильная/дорогая пагинация экспорта.** Первый staging-прогон остановлен на90 страницах SP10: каждая страница повторно собирала ZIP, а добавление в журнал могло менять снимок между страницами. Прежний неполный прогон не объявлен PASS. Минимальный патч фиксирует первый снимок под workspace lock, хранит SHA-bound ZIP и index с проверкой пути/хеша, читает одну требуемую часть. Regression проверяет append между страницами, отсутствие повторной сборки и отказ на corruption. После патча повторены302 tests, установленный wheel,13 опытов и полная MCP-приёмка.
2. **Разделение меток.** Протокол v1 содержал IDs, производные от variant-bit. Исправлено до первого inference: v2 IDs зависят только от pair ID и SHA текста. Никакие оценки v1 не использованы. Fit фиксируется до чтения query, внешние метки доступны лишь post-hoc оценщику за границей worker sandbox.
3. **Явная область противоречий.** Первичный опыт сохраняет все1484 учебные записи с `retain_as_empirical` и CONTRADICTORY_TRAINING. Строгий контроль отказывается от модели; условное исключение228 записей выделено отдельным вторичным опытом. Нельзя выдавать условную выборку за весь корпус.
4. **Иерархия источника.** Четыре строки не означают доказанный quatrain: контекст line_in_quatrain разрешён только при source-supplied hierarchy, иначе line_in_source_record. Подлинные корпусные уровни и UTF-8 spans сохранены.

## Почему перенос не получился

Global-alpha quotient теряет различия, необходимые для метки «исходный/переставленный»;78 из942 пар тождественны уже в этом представлении, включая II.5 и VII.2. На200 heldout парах16 неидентифицируемы и183 имеют равные оценки; единственное предпочтение неверно. Невозможно восстановить уничтоженное различие перебором того же observer basis. Более информативный punctuation baseline сильнее в этой конкретной задаче, но это не свидетельство общего понимания текста.

Реальные ограниченные композиции существующих операций проверяются по AST и трассам. Однако конечный перебор не нашёл нового переносимого наблюдателя: NO_VERIFIABLE_NEW_OBSERVER. Нельзя переименовать builtin pair_0_max в новое открытие или добавить языковую эвристику после просмотра holdout.

## Минимальная следующая исследовательская проверка

Новый заранее фиксируемый train-only контекст, сохраняющий уничтоженные различия, отдельный blind corpus и тот же punctuation baseline. Не менять метрику текущего опыта, не дорисовывать семантические метки и не запускать такой новый опыт под видом повторения этого релиза. Уникальная грамматика и семантическая интерпретация остаются UNDERDETERMINED/NOT_PROVED.

Ни один отрицательный результат не удалён. Полные успешные production-трассы и исходные журналы разработки сохранены; runtime не выполняет код из экспортов.
