# RCA — Symbolic V1

## Содержательный результат и его пределы

Полные слова действительно различают SSPP/SPSP при одинаковом q=0; локальная и глобальная α-канонизация не смешиваются. На sealed synthetic test есть конечное преимущество обученной структурной гипотезы над простыми baseline в двух семействах. Это проверка библиотеки общих отношений равенства/повторов/счётчиков/префиксов и обучаемого bounded tree, не универсальное восстановление неизвестной грамматики.

**Отрицательный результат E:** на всех20 seed Pareto-выбор и random-local дали одинаковые числа состояний/свидетелей; средние nodes76.8, witnesses342.6 при32 шагах×4 кандидата. У этой библиотеки наблюдений многие множества новизны несравнимы, так что обе стратегии выбирают тем же seeded tie-break. Следовательно превосходство Удава над случайным локальным поиском **не подтверждено**; предсказательный выигрыш нельзя приписывать поиску. Это сохранённый отрицательный контроль, а не неисправность выдачи метрик.

На периодическом языке преимущество перед сильным alpha-context baseline практически нулевое: +0.0391 процентного пункта, paired95% bootstrap CI включает0. Статус NO_EVIDENCE_OF_GAIN сохранён.

Для Малларме и Нострадамуса нет разметки истинной грамматики, а четыре обучающих строки не идентифицируют её. Поэтому membership_accuracy=NOT_ASSESSED_NO_NATURAL_GRAMMAR_ORACLE, grammar=UNDERDETERMINED; посчитаны только объявленные heldout next-token NLL и структурные артефакты. Layout не предоставлен: UNAVAILABLE. Выбран текст Нострадамуса из конкретной редакции1867, с её вариантами, без заявления о тождестве изданию1555. Семантические открытия/пророчества/новая физика не проверялись.

## Исправления в ходе разработки

- Проверка биективности local RENAME первоначально захватывала весь алфавит корпуса. Теперь область — выбранная запись; глобальное совпадение после локального переименования допускается и не выдаётся за глобальную α-эквивалентность.
- Сравнение α-класса дополнено границами; одинакового рисунка токенов недостаточно при разной структуре сегментов.
- Строковый путь workspace приводится к Path до recovery. NFC literal tokens сохраняют исходный span и не могут разрезать нормализуемый кластер.

## Сохранённые ошибки первых запусков проверки

1. Лёгкий тестовый venv не содержал tiktoken для legacy-сервера. Использована существующая полная среда production; зависимости/проверки не ослаблялись.
2. Шесть legacy subprocess-тестов из корня не находили bare imports. Полный набор повторён из live_math_mcp_prod, как требует инструкция проекта:1066 PASS,20 SKIP. Лог неправильного cwd сохранён.
3. Новый test helper дважды передавал max_steps в dict.update. Исправлено объединение аргументов.
4. Новый клиентский тест крупного artifact читал только первую страницу и получал незавершённый JSON. Исправлен обход next_offset; серверный лимит112 KiB и проверка полной длины не ослаблялись.
5. Первый staging запуск был фоновым потомком завершившейся exec-сессии. Он остановился до listen. Rehearsal запущен в собственной сохраняемой сессии; production не затрагивался.
6. Новый QA-runner ошибочно ожидал от прежнего numerical replay новый symbolic status REPLAY_MATCH. Старый контракт возвращает PASS; проверяется именно PASS, runs_recomputed=1, network=DISABLED. Исходный FAIL сохранён, новый полный прогон прошёл138 проверок.

Все исходные неуспешные логи входят в поставку отдельно от итоговых PASS. Повторное выполнение не меняло train/test:60 frozen models, все наборы данных и предсказания совпали побайтно между первым и финальным прогоном.
