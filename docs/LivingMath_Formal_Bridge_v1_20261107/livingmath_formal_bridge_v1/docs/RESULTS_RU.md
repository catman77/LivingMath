Для синхронного переименования терминалов **и** всех грамматических ролей проверена ковариантность на 5461 слове над четырёхсимвольным алфавитом длины 0–6. Для parity DFA — полный контроль всех 1023 бинарных слов длины от 0 до 9. Также:

- `ε` различает nullable и non-nullable `a^n b^n`.
- `abab` отличает Dyck(1) от nullable `a^n b^n`.
- `SB` отличает строго типизированный Dyck(2) от модели, которая игнорирует тип закрывающей скобки.
- `aaa` в `S→SS|a` даёт **минимум два разных** дерева вывода, которые не уничтожаются одним membership.
- Подмена production ID, terminal span/leaf и DFA transition trace отвергнута независимыми проверками.
- Три FOL-чтения одной русской фразы **типизируются** под явно заданной сигнатурой; перепутанные сорта и свободные переменные отвергаются; две проверочные модели дают различающиеся truth vectors; найдены конечные контрмодели для всех трёх пар интерпретаций.

Все исходные проверки программно воспроизводимы; JSON-результат в `results/reference_acceptance.json`. Реализация использует **явно записанные reference-grammar AST** и ручные варианты FOL-интерпретаций; она доказывает лишь то, что целевой формат *может* представлять эти объекты и они допускают проверку. Она **не доказывает, что сервер их самостоятельно открыл**.

## D. Главный RCA

Ранее исходная гипотеза `a^n b^n (n≥1)` выглядела успешной (256/256), но дополнение контролем `ε` показало неразличение `n≥0` и `n≥1`. Эта ошибка устраняется **разделением nullable-начала**, а не увеличением числа слов длины 20. Сейчас reference layer это различает. Следующая реальная инженерная работа — сделать так, чтобы **синтезирующий MCP** сам мог открыть обе программы и вернуть активный запрос `ε`.

## E. Исполнимость и граница

Отчёт не сообщает научной новизны по стандартным CFG/FOL алгоритмам и не притворяется подтверждённой универсальной «семантикой мира». Наиболее содержательный новый объект исследования — выбор и сравнение *пространства формальных представлений*, в котором грамматические/логические контрпримеры помогают локализовать нехватку выразительных примитивов.
