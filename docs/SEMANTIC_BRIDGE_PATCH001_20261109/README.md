# SEMANTIC-BRIDGE-PATCH001 — пакет для кодового агента

**Дата:** 2026-11-09. **Статус:** ТЗ, промпт, схема API и испытания; **не реализация**.

**Порядок чтения:**
1. `TZ_RU.md` — обязательный контракт и границы изменений.
2. `PROMPT_CODING_AGENT_RU.md` — готовое задание исполнителю.
3. `API_EXAMPLES.json` — контрактные запросы/ответы в виде примеров, не существующие пока эндпоинты.
4. `ACCEPTANCE_MATRIX.json` — критерии G0–G9, которые агент должен реально выполнить.
5. `reference/` — исходная теория и неизменённые доказательные материалы SB-EXP01.

**Исходники:** `https://github.com/catman77/LivingMath`, базовый commit `e65b1a1e06914d63f6048a04b5e065a610adb68d` (main на момент составления), действующая среда LivingMath v0.4.12-developer-preview. Не доверять предположению, что ветка или сервер остались неизменны: перепроверить SHA и tools/list непосредственно перед внедрением.

**Запреты:** не изменять native White Star / UDAV / NOPS / CAD; не встраивать LLM в новый слой; не объявлять соответствие смыслу доказанным; не выдавать конечную неразличимость за логическую эквивалентность.

`MANIFEST_SHA256.txt` содержит SHA-256 всех остальных файлов пакета. После реализации агент должен выпустить собственные новую поставку и отчёт о проверках, а не приписывать файлам данного архива статус внедрённого кода.
