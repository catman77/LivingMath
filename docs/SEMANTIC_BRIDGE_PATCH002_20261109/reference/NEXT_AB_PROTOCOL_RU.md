# Следующий строгий A/B-эксперимент (дизайн; не выполнен)

Цель: проверить, повышает ли MCP вероятность *правильного, семантически лицензированного* исправления ошибочного чтения естественного языка, а не просто количество формальных конструкций.

## Протокол

- Сформировать ≥48 новых, ранее не используемых задач: кванторы/отрицание, анафора и речевые акты, пресуппозиции, временные и модальные конструкции. Часть задач должна допускать `ABSTAIN`.
- До запуска зафиксировать источники, права, экспертные эталоны и критерии частичного успеха; экспертам не сообщать, какой arm предлагал ответ. Согласование разногласий между двумя разметчиками протоколировать отдельно.
- Сначала одинаковой LLM с фиксированными моделью, reasoning budget, параметрами и лимитом токенов дать первичную формализацию. Заморозить ответ с SHA.
- Назначить случайным образом контрольные режимы: (A) исходный текст и обычный самоанализ; (B) текст плюс базовый finite FOL checker; (C) текст плюс Semantic Bridge и реальные контрмодели; (D) такой же объём структурных данных, но без информативной связки со смысловыми кандидатами, явно маркированный контроль, чтобы не вводить модель в заблуждение о подлинности свидетельств.
- После одинакового количества шагов измерить корректность финальных AST относительно независимого эталона, честный `ABSTAIN`, обнаружение нелицензированных фактов, восстановление пропущенных предпосылок; а также стоимость, latency, tokens, число проверяемых математических выводов.
- Переход между режимами для одних и тех же задач только в строго контролируемых независимых сессиях, без утечки предыдущих ответов. Учитывать модель и задачу как парные факторы.
- Повторить для маленькой модели и большой модели; оценить взаимодействие `model_size × MCP_mode`, а не общий средний балл.
- Основной показатель: изменение доли семантически корректных (или корректно воздержавшихся) ответов на заранее выделенной тестовой выборке. Доверительные интервалы — парный bootstrap и, где применимо, McNemar; не заявлять выигрыш по 6 удобным кейсам.

Критический guard: сервер должен *не* выбирать «правильный» русский смысл автоматически на основании истинности формулы в модели. Контрмодель отличает формулы, а не доказывает намерение автора.
