# Semantic Bridge PATCH002 — пакет на исправление EXP02

Данный ZIP — **только ТЗ и промпт**, не установленный код. Направлен на два выявленных недостатка: (1) неравномерный расход модельного бюджета в направленных сравнениях FOL; (2) семантическая подмена LLM содержания сообщения объективной истинностью этого сообщения. Исправление (2) реализуется протоколом LLM и журналом явных обязательств, а не претензией MCP на понимание языка.

## Файлы

- `TZ_RU.md`: полное ТЗ для кодового агента.
- `PROMPT_CODING_AGENT_RU.md`: готовый промпт для агента.
- `ACCEPTANCE_MATRIX.json`: критерии G0–G10.
- `fixtures/PATCH002_CASES.json`: точные исходные конструкции/ожидаемые свойства.
- `fixtures/REFERENCE_VERIFY.py`: независимая минимальная проверка ключевых логических тождеств без кода LivingMath.
- `LLM_SEMANTIC_AUDIT_PROTOCOL_RU.md`: протокол работы модели, который агент должен встроить в клиентскую документацию.
- `BASELINE.json`: реальные версии/sha кода, которые надо перепроверить при старте.
- `reference/`: выдержки из фактического EXP02 и независимые данные (не переписывать и не выдавать за новый тест).
- `SHA256SUMS.txt`: SHA256 каждого файла пакета, кроме этого самого манифеста.

Инструкция: передай архив кодовому агенту вместе с фразой «Выполни промпт `PROMPT_CODING_AGENT_RU.md`; не трогай native/legacy; верни delivery ZIP с действительными тестами и SHA». После обновления сервер проходит **отдельную независимую приёмку**.
