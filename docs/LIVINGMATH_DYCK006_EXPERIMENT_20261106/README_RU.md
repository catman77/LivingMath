# EXP-DYCK-006

Исследовательский пакет реальных прогонов LivingMath v0.4.7 и независимого конечного эталона. **Не установленное расширение сервера.**

- `01_REPORT_RU.md`: экспериментальные результаты MCP и границы выводов;
- `02_FORMAL_NO_GO_RU.md`: доказательство недостаточной выразительности класса equality-only AST;
- `03_NEXT_TECHNICAL_SPEC_RU.md`: предложение следующего исследовательского изменения;
- `04_AGENT_PROMPT_RU.md`: готовая инструкция кодовому агенту;
- `reference/dyck_certificates.py`: независимые функции префиксной допустимости, конечные сертификаты двухветвевой грамматики и множества продолжений;
- `reference/test_dyck_certificates.py`: 24 независимых локальных теста;
- `data/live_runs.json`: реальные новые серверные идентификаторы и результаты;
- `data/finite_census.json`, `data/future_classes.json`: контролируемые конечные числа;
- `SHA256SUMS.txt`: хеши файлов.

Для локальной проверки: `cd reference && python -m unittest -v test_dyck_certificates.py`.

Граница: фраза `BOUNDED_CATALOG_CHECKED` говорит о проверке конечного каталога, НЕ о глобальном переборе всего пространства грамматик. Процедура для языка Дика в эталоне **заранее задана**; LivingMath v0.4.7 её самостоятельно не нашёл.
