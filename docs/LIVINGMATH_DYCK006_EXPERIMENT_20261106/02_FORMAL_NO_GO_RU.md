# Формальная граница существующего каталога

## A. Алфавит и право переименования

Пусть Σ={S,P}. Для слов Σ* действуют биекции σ:Σ→Σ, продолжаемые посимвольно на слова. На словах определены следующие операции и наблюдения:

* литеральное равенство атомов (`x=y`), в частности равенство удалённых позиций;
* разрез по позиции, SPLIT;
* CONCAT;
* REVERSE;
* комбинация через `AND/OR` и рекурсивное применение к строго меньшему фрагменту.

Каждый из этих операторов эквивариантен относительно σ, а любой тест равенства инвариантен. Условные переходы, управляемые только такими тестами, тоже инвариантны. По структурной индукции по AST (и строгой индукции по длине для рекурсивного случая):

    f(σ(w)) = f(w).

Проверенный каталог MCP от 2026-11-06 содержит `aligned_token_equality`, `compare_fragments` и `iterate_on_inner_fragment` — ни одна конструкция **в этом каталоге** не объявляет роль символа OPEN или CLOSE.

## B. Контрпример

Dyck-грамматика задаёт

    D := EPS | OPEN D CLOSE D.

При фиксированном контракте `OPEN=S`, `CLOSE=P`:

    D(SP)=True,
    D(PS)=False.

Но `σ(SP)=PS` при σ(S)=P и σ(P)=S. Поэтому никакая функция, инвариантная относительно σ, не классифицирует обе пары правильно.

**Граница формулировки:** результат относится только к указанному классу AST, а не ко всем алгоритмам и не ко всей математике S/P.

## C. Правый остаток и неограниченное семейство различимых контекстов

Определим `R_u={v : uv ∈ D}`. Если у слова `u` есть префикс с количеством CLOSE больше количества OPEN, то `R_u=∅`, поскольку никакой будущий суффикс не исправит уже нарушенную префиксную допустимость. Иначе остаток определяется текущим незавершённым структурным стеком из OPEN.

Для каждого h≥0 префикс `S^h` имеет допустимый суффикс `P^h`, но ни `S^k` для k≠h этот же суффикс не завершает до нуля. Поэтому `R_{S^h}` попарно различны, и разных правых контекстов бесконечно много. По критерию правой конгруэнции это означает, что язык Dyck не распознаётся одним конечным автоматом фиксированного числа состояний для всех длин.

Для конечного горизонта N и всех префиксов длины ≤N получаем N+1 структурных состояний незакрытых OPEN (h=0..N) плюс один поглощающий класс нарушенной ориентации, т.е. N+2 класса при N≥1. Именно это независимо подсчитано в эталоне (N=1..6).

## D. Почему нормальная форма SP-ноля недостаточна

Поскольку обе редукции `SP->EPS` и `PS->EPS` разрешены, любое сбалансированное S/P-слово сокращается к EPS, однако принадлежность Dyck зависит от направления. Поэтому отображение `NF` склеивает несовместимые по Dyck слова, и никакой `f(NF(w))` не даёт Dyck для всех слов.

Указанное не отменяет полезности S/P-ноля: он отвечает на иной математический вопрос. Восстановление ориентированной грамматики требует сохранения части истории/порядка, уничтожаемой факторизацией.

## E. Конструктивная возможность, но ещё не открытие сервером

Типизированная грамматика `EPS|OPEN D CLOSE D` с уже существующими SPLIT/CONCAT, проверкой роли и двумя рекурсивными ветвями формально представляет нужный язык. `reference/dyck_certificates.py` предъявляет конечные свидетельства и verifier. Это **независимый gold oracle**, а не выдача LivingMath и не доказательство уникальности автоматически восстановленной грамматики.
