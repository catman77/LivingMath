# LM-NL-PROPOSER-002: реализация и приёмка

Реализован отдельный NLProposalBridge/1 и два opt-in инструмента в существующем
MCP. Оригинальный архив сохранён без изменений в docs. Все91 старые контракты и
численное/символьное/formal ядра сохранены. Версия поставки0.4.10 developer preview.

Настоящий owner-hosted provider через ChatGPT login даёт source analysis и
несколько FOL proposals; generic typed decoder использует проверенные source
orders реальных кадров/узлов, записывает AST до/после, предпосылки и конкурентов.
Контрмодели вычисляет прежний Formal Bridge. Происхождение, типизация и смысл
разделены; verified и execution grants не назначаются.

447 source PASS,447 installed-wheel PASS,1066 legacy PASS/20 прежних SKIP,
31 старый gate и формальные1024 решения проверены. P0 spoofing отклонён;
source-only, traced generation, finite contrast, idempotency, admission и
offline replay имеют реальные receipts. Исходные ошибки и исправления сохранены.

Слепой набор:36 новых основных текстов,8 renamed,2 adversarial verbs,4 controls.
Четыре плеча A/B/C/D завершены с одинаковыми nominal budgets и свежими вызовами.
Gold независимого synthetic holder открыт после заморозки всех кандидатов.
Итоговые числа, source/AST SHA, реальные run refs и расходы —
[RESULTS_B_C_RU.md](RESULTS_B_C_RU.md), ARM_ABLATION_MATRIX.json,
SOURCE_ALIGNMENT_MATRIX.json, MODEL_CONTRAST_EVIDENCE.json и полные traces delivery.

Инженерная интеграция принимается отдельно от научной. Семантическая точность
не оценена людьми: PARTIAL / EXTERNAL_ADJUDICATION_NOT_EXECUTED /
semantic generalization NOT_EVALUATED. WHITE_STAR_INCREMENTAL_BENEFIT_NOT_ESTABLISHED.
Synthetic finite vector agreement не является логической эквивалентностью.
Production и GitHub подтверждаются отдельными DEPLOYMENT/INTEGRITY/PUBLICATION
receipts; незапущенные действия остаются NOT_EXECUTED до фактической проверки.
