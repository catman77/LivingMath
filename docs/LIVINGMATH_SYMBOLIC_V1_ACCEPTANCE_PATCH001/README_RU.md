# LivingMath symbolic_v1 — приёмка и PATCH-001

Дата: 2026-11-05. Проверенный сервер: `v0.4.0-developer-preview`, `symbolic_v1/1`, deployment `symbolic-v1-20261105T055049Z`.

**Решение:** условная приёмка инфраструктуры и точной символьной семантики; исследовательская приёмка индукции грамматики НЕ закрыта. Исправлять узко, не переписывать Удава, численное ядро Белой звезды или старые MCP-команды.

Файлы:
- `01_ACCEPTANCE_REPORT_RU.md`: результаты живых вызовов MCP, идентификаторы, статусы и ограничения.
- `02_TZ_PATCH001_RU.md`: конкретное ТЗ на доработку.
- `03_PROMPT_CODE_AGENT_RU.md`: готовый промпт агенту.
- `04_TEST_PROTOCOL_RU.md`: независимые проверки и критерии выпуска.
- `fixtures/acceptance_runs.json`: машинно-читаемый журнал доказательств.
- `checks/heldout_palindrome.py`: автономная проверка существующего прогноза на известном контрольном корпусе.

Важное разграничение: `proved_exact` означает точное конечное утверждение в реализованной грамматике, не теорему о естественном языке. `empirical` и `UNDERDETERMINED` не следует автоматически повышать до доказательств. Литературная интерпретация не сертифицируется сервером.

Никакой актуальный исходный код сервера в этот архив **не включён**: он остаётся в репозитории исполнителя. Этот архив содержит спецификацию и воспроизводимые данные, а не вымышленный патч к невиданным файлам.
