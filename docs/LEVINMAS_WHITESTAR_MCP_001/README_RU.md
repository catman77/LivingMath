# LevinMAS × Белая звезда: код, ТЗ и промпт — MCP-001

Пакет для **добавления второго режима в существующий подключённый сервер**: LevinMAS/SUTI и LevinMAS/Белая звезда. Имя подключённого приложения — LivingMath; фактическое имя сервиса — SUTI-Bridge-LivingMath. Это один целевой сервер с отдельными командами.

## Начать здесь

1. Передайте кодовому агенту **весь распакованный архив**.
2. Дайте ему текст из `PROMPT_CODEX_RU.md`.
3. Основное задание — `TZ_RU.md`; сравнение режимов — `docs/COMPARISON_PROTOCOL_RU.md`.
4. Готовый код находится в `code/`, рабочий общий вход к нему — `integration/white_star_adapter.py`.

Сам репозиторий действующего LevinMAS агент использует из своего целевого checkout; старую копию сервера поверх него не накатывать.

## Быстрый локальный запуск

Linux, Python 3.10+, C++17. Версии NumPy/pandas зафиксированы в готовом requirements. Команды из корня распакованного архива:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r code/experiments/white_star/requirements.txt
.venv/bin/python scripts/verify_bundle.py --report /tmp/white_star_qa.json
.venv/bin/python integration/white_star_adapter.py --input fixtures/blok_request.json --output /tmp/white_star_blok.json
.venv/bin/python integration/white_star_adapter.py --input fixtures/original_request.json --output /tmp/white_star_original.json
```

При первом запуске собирается native .so. В архив намеренно включён переносимый исходник, а не бинарник конкретной машины. Для эксплуатации компиляция должна происходить при сборке/старте сервиса, не в обработчике пользовательского запроса.

Локальный адаптер выполняет численный поиск и формирует данные для LLM. Новую прозу он не сочиняет: её пишет вызывающая LLM. Он **ещё не реализует** MCP-регистрацию, постоянный журнал, SUTI ingress или развёртывание — именно эти работы заданы в ТЗ.

## Проверенная база и границы

- Целевой сервер на момент инспекции: `v0.1.0-developer-preview`, deployment `release-v01-20261104T181130Z`, 55 видимых команд.
- Его поле `SUTI_native_runtime` сейчас равно `NOT_EXECUTED`. Это должно оставаться видимым в сравнении.
- Белая звезда: оригинальные свидетельства символного деления, исходный выбор Удава и численные сигнатуры сохранены.
- Блок/003: 64 шага, 192 проекции, 354 численные карты, 360 подписанных отображений, 52 посещённых качественных режима.
- Три формальных переноса — конечные линейные модели над рациональными числами. Их машинные проверки не доказывают литературную трактовку или закон природы.
- Полный перебор достижимых режимов находится только в диагностике. Боевой путь его не вызывает.
