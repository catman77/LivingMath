# Проверка этой поставки

Выполнено локально 2026-11-05, Linux x86_64, Python 3.12.14, NumPy 2.3.5, pandas 2.2.3. Полная версия компилятора и измерения — ENVIRONMENT_AND_TIMING.json.

- Все **75 файлов code/** побайтово совпали с архивом NOBS_WhiteStar_LLM_003_Transfer.zip; результат — SOURCE_COPY_CHECK.json.
- Пройдено **29 unittest checks**: 5 в 001, 8 в 002, 8 в 003 и 8 в новом адаптере. Логи — RUN_REPORT.json.
- Новый адаптер точно воспроизвёл полные трассы 001 и 003. Для cj_v1 сохранены 354 уникальные карты / 360 подписей, 64 шага / 192 проекции и 52 качественных режима.
- Второй, оригинальный текст обработан без привязки к Блоку: 4 понятия, 24 карты, 32 шага / 96 проекций, 18 качественных режимов. Это тест работоспособности адаптера, не оценка литературной ценности.
- JSON Schemas и оба входа проверены jsonschema 4.26.0; входные схемы шести предлагаемых MCP-команд валидны. Проверены четыре отклоняемых некорректных входа. См. SCHEMA_CHECK.json; воспроизведение — scripts/check_contracts.py с requirements-qa.txt.
- Медиана полного прогретого локального адаптера в 11 повторах — около **8 мс**. Включены копирование/проверка входа, атлас, native поиск, кадры, decoder packet, JSON digest и проверка размера. Импорт, компиляция, журнал сервера, удалённый транспорт, SUTI и LLM сюда не входят.

Существующее подключение проверено чтением status/catalog. Новые MCP-команды пока описаны контрактами; живой MCP smoke, SUTI ingress, постоянный журнал и deployment являются задачами следующего кодового агента. В этой поставке они не выдаются за выполненные.

Сохранённая проза старых опытов — ранее полученные ответы LLM. При сборке этого пакета API-вызовы новой LLM-генерации не выполнялись. Новый короткий текст и его разметка — явная QA-фикстура, написанная ассистентом.
