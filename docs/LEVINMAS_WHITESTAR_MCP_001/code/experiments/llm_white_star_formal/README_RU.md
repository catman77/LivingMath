# NOBS WhiteStar LLM 002 — формализация опыта 001

Этот пакет делает проверяемым ранее полученный литературный опыт. Новый поиск
и новые толкования не запускались: изучены **те же** вход, 64 наблюдения и шесть
текстов. Ядро Белой звезды/CAD/Удава осталось побайтно прежним.

Начните с `experiments/llm_white_star_formal/REPORT_RU.md`.
Точные определения и доказательства находятся в
`experiments/llm_white_star_formal/FORMAL_SPEC_RU.md`.

## Основные результаты

- Точно определён достижимый набор из **344 качественных режимов** связи.
- В исходном прогоне посещены **58 режимов**, 47 пар понятий.
- Первые шесть кадров различны после удаления общих масштабов и порядка строк.
- У **44 из 90 пар** тип согласование/напряжение фиксирован координатами.
- Найдены **5 случаев** численной новизны без нового качественного режима.
- Для шести текстов построены **18 адресованных соответствий** выбранным связям.
- **11 преднамеренных ошибок** отклоняются проверкой; 8 тестов проходят.
- Проверка честно не оценивает литературный смысл: подстановка пустой прозы
  показывает границу того, что может установить вычислительный сертификат.

344 — не число возможных смыслов: это число режимов определённого readout.
Доказательство полноты использует корни четырёх линейных функций на отрезке,
а не длительный прогон или перебор литературных вариантов.

## Воспроизведение

Python 3.10+, зависимости прежнего опыта:

```bash
python -m pip install -r experiments/white_star/requirements.txt
python experiments/llm_white_star_formal/run.py --output replay_formal
python -m unittest discover -s experiments/llm_white_star_formal -p 'test_*.py' -v
```

Эта постпроверка использует Python-референс и точные рациональные числа;
компиляция C++ не требуется. Полный опыт 001 с исходным native-ядром также
включён и запускается отдельно:

```bash
python experiments/llm_white_star/run.py --output replay_001
```

Второй запуск требует Linux и компилятор C++17. Он воспроизводит численную
часть; сохранённую литературную прозу не заменяет новым вызовом модели.
