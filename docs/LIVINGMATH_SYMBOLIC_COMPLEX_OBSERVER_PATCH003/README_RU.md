# LivingMath — SYMBOLIC_COMPLEX + OBSERVER_SYNTHESIS v1 (PATCH-003)

**Назначение:** единый исполнимый пакет для кодового агента, реализующего следующую версию MCP поверх работающего `symbolic_v1/1-patch002`. Дата подготовки: 2026-11-06 (воспроизводимые исходные эксперименты: 2026-11-05).

## Сначала прочитать

1. `01_RCA_AND_DECISIONS_RU.md` — проверенные исходные результаты, RCA, решения и границы выводов.
2. `02_TECHNICAL_SPEC_RU.md` — полное инженерное ТЗ с P0/P1/P2, stop conditions.
3. `03_AGENT_PROMPT_RU.md` — **готовый промпт кодовому агенту**: передать целиком вместе с ZIP.
4. `04_FORMAL_MODEL_RU.md` — математическая семантика 0/1/2-клеток, гомотопий и наблюдателей.
5. `05_MCP_API_CONTRACTS_RU.md` — предложения по аддитивным MCP-интерфейсам и точным сертификатам.
6. `06_ACCEPTANCE_PROTOCOL_RU.md` — матрица приёмки, отрицательные тесты, эксплуатационные gates.
7. `07_RESEARCH_PROGRAM_RU.md` — S/P сначала; Нострадамус как независимый сложный корпус.
8. `08_RELEASE_AND_REPORTING_RU.md` — формат сдачи, provenance и статус свидетельств.

`reference/sp_complex_reference.py` — **рабочий** независимый конечный эталон 2-комплекса S/P (stdlib-only, не production-патч). `tests/test_reference.py` — автоматические unit/metamorphic/negative проверки; `fixtures/` — машинные эталоны и примеры предлагаемых контрактов. `CHECKSUMS_SHA256.txt` — контроль целостности ZIP-пакета.

## Команды проверки эталона

```bash
python3 tests/test_reference.py
python3 reference/sp_complex_reference.py --max-len 10
python3 reference/sp_complex_reference.py --max-len 8 --face-policy none
```

Для сформулированного 2-комплекса при `max_len=10` получено: `V=351`, `E=1614`, `graph_beta1=1264`, `faces=3360`, `rank_d2_F2=1264`, `H1_F2_dim=0`, и отдельно создаётся **индуктивный сертификат стягивания путей**. При `--face-policy none` `π1` **не объявляется тривиальной**: это контроль от ложного вывода из одного лишь графа. Код проверен локально перед упаковкой.

## Что это НЕ является

- Это **не** скачанная копия исходного кода продакшн-MCP: у автора пакета нет доступа к рабочему дереву сервера. Кодовый агент обязан делать точечный патч в реальном репозитории, а не выдавать эталон за интеграцию.
- Это **не** доказательство «фундаментальной группы нуля» без выбора конкретной топологии. Сертификат относится **только** к явно указанному конечному клеточному комплексу.
- Это **не** обещание открытия семантики Нострадамуса или универсальной грамматики. Реальные тесты требуют слепого контроля, базовых сравнений и честного `UNDERDETERMINED`.

**Главное ограничение:** оставить нетронутыми численное ядро Белой звезды, старые `base_v1`/`cj_v1`, модели SUTI, хранение immutable runs, privacy/sandbox, replay и рабочий API `white_star_symbolic_*`. Новое — **дополнительный** модуль, а не переписывание всего сервера.
